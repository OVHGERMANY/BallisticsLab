# Known Issues and Limitations

No reproducible defect is confirmed for `0.3.0-alpha.1` at publication time. New reports remain unconfirmed until they can be reproduced or supported by sufficient evidence.

## Known limitations

- Only SPT 4.1.2 / EFT 0.16.9.40743 is supported.
- The plugin is disabled by default and requires a restart after changing its master switch.
- Physical transition evidence is available only when a compatible schema-2 publisher is already loaded.
- Reports are simulation evidence. GOST-oriented screens are explicitly non-certifying and cannot replace physical laboratory testing.
- The current database lacks some exact threat and material combinations; unavailable cases fail closed instead of substituting a misleading fixture.
- Broad runtime compatibility, UI scaling, long-session performance, and report-volume evidence is still being collected.
