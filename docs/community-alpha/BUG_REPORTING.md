# Bug Reporting

Use the repository's structured form that best matches the defect. Search open issues before creating a duplicate.

Include the exact version, release tag, commit, SPT/EFT versions, hardware, installed mods, round, weapon and barrel, fixture or target, expected and actual behavior, numbered steps, frequency, relevant configuration, and the smallest useful log excerpt. Attach a JSON/CSV report when the defect concerns telemetry, conservation, lineage, fixture identity, or a controlled campaign.

Do not upload a full game directory, EFT DLL, EFT asset, profile, credential, or private key. Review reports, logs, screenshots, and videos for personal information before attaching them.
